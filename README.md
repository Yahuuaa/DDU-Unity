# Teknikfag A - Eksamensprojekt
Dette er et citybuilder-spil udviklet i Unity som eksamensprojekt til Teknikfag A

## Installationsvejledning
1. Installer eller klon projektet fra dette repository
2. Installer Unity Hub og herefter Unity Editor med version 6000.3.2f1
3. Under Unity Hub, tilføj der hvor du har lagt projektet på din computer og åben det
4. Til slut kan du blot klikke på start knappen i toppen af din Unity Editor
